# Reverse Polish Notation Evaluator

A simple Python implementation of a Reverse Polish Notation (RPN) expression evaluator.

The evaluator supports basic arithmetic operations, exponentiation, modulo operations, integer division, and common unary functions such as square root and absolute value.

## Features

- Evaluates space-separated RPN expressions
- Supports:
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
  - Integer division (`//`)
  - Modulo (`%`)
  - Exponentiation (`^`, `**`)
  - Square root (`sqrt`)
  - Absolute value (`abs`)
- Simple implementation using a stack-based evaluation approach

## Example

Input: `3 4 + 2 * 7 /`

Output: `Result: 2`


## Purpose

This project is mainly intended as a learning resource and a practical example of how Reverse Polish Notation can be implemented in Python.

Feel free to explore, modify, and experiment with the code!
